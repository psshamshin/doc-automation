# AGENTS.md - doc-automation

Проект готовит правки документации LUNA POINT 2 (RU и EN) и release notes по изменениям фронтенда.
Описание: `README.md`. Правила: `docs/RULES.md`.

## Разработка

- Python 3.9+, без сторонних пакетов. Тесты: `python3 -m unittest discover -s tests`.
- Постоянные имена папок и компонентов: `pipeline/product.py`. Настроек релиза нет: версии читаются из данных.
- Правило меняется в `knowledge/rules.json` или `pipeline/units.py` и описывается в `docs/RULES.md` (только действующее
  состояние, без истории). У каждого правила есть тест.
- В git не попадают `input/`, `output/`, `reference/`. В тестах только придуманные данные из `tests/data/`.
- В новом тексте не использовать букву «е с двумя точками» и длинные тире.

## Агент (для агента, запущенного вручную)

Его папка - `output/<релиз>/agent_workspace/`. Правила и формат ответа лежат в `AGENTS.md` этой папки (шаблон:
`agent/prompts/workspace_agents.md`). Кратко: файлы документации не меняет, правки и выводы возвращает ответом,
подтверждает цитатами, документацию техписа (`reference/`, `input/*/docs-reference`) не читает.
