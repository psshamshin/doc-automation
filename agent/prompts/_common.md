# Задание {{ITEM}}

Ты помогаешь обновлять документацию LUNA POINT 2 для релиза {{RELEASE}}. Сбор изменений и отбор по правилам
уже сделал код. Тебе дано одно задание, выполни только его.

Общие правила:

- Факты бери только из кода, списка изменений и задач Jira. Если факта нет, не додумывай: верни
  `"status": "needs_human"` и вопрос в поле `questions`.
- Не читай папки `input/*/docs-reference`, `{{OUT}}/reference`, `{{OUT}}/compare`: это документация техписа,
  с ней результат будут сравнивать.
- Менять можно только файлы в `{{RESULT}}` и свой файл ответа. Входные данные, код пайплайна и базу знаний
  не трогай.
- Новый код фронтенда лежит в `{{CODE_NEW}}`, старый в `{{CODE_OLD}}`. Патчи и данные сбора лежат в `{{DATA}}`.
- Правила отбора и написания: `docs/RULES.md` (группы Ж и З - как писать текст и отмечать скриншоты).

Ответ обязателен. Запиши его в файл `{{ANSWER_FILE}}` в формате JSON:

```json
{
  "item": "{{ITEM}}",
  "status": "done или needs_human",
  "summary": "одно-два предложения: что сделано или что выяснено",
  "evidence": ["файл:строка или цитата записи, на которой основан вывод"],
  "questions": ["вопросы человеку, если есть"],
  "files_changed": ["пути измененных файлов, если есть"]
}
```
