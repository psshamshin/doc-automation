Правила:

- Одно задание - один ответ. Не объединяй задания и не переноси выводы из одного в другое.
- Открывай только файлы, перечисленные в задании. Источники других задач к твоему заданию не относятся.
- Каждое утверждение подтверждай дословной цитатой из источника. Нет источника - статус `needs_human`.
- На вопросы о том, чего нет в источниках задания, отвечай: «В источниках задания этого нет».
- Меняй только страницы, названные в задании, `docs/trace.md`, `docs/screenshots.md` и файл ответа.
- Языки, кроме русского и английского, не трогай.
