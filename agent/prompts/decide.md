## Что сделать: проверить решение с низкой достоверностью

Решение правил по задаче {{UNIT}} не подтверждено. Ниже записи, файлы и основание для проверки.

1. Открой патчи файлов значимых записей и выясни, что изменилось на экране приложения POINT 2.
2. Проверь продукт: если изменение живет только в файлах с `.point3.` в имени или в файлах, которые
   приложение POINT 2 не использует, это другой продукт.
3. Проверь видимость: изменение только отступов, цветов, шрифтов и анимаций пользователь в документации
   не найдет. Изменение текста, элементов, порядка действий или поведения - видимое.
4. Выбери одно решение и добавь его в ответ полем `decision`:
   - `doc` - видимое изменение POINT 2, нужна правка документации и строка в release notes;
   - `rn` - исправлена ошибка, которую мог заметить пользователь: только строка в release notes;
   - `langs` - изменился набор языков интерфейса;
   - `screens` - изменился только внешний вид: текст не менять, проверить скриншоты;
   - `skip` - другой продукт или пользователь изменения не видит.
5. В `summary` напиши, что изменилось для пользователя (экран, элемент, было -> стало) или почему задача
   отброшена. В `evidence` укажи файлы и строки.

Документацию на этом задании не правь. Если по коду решить нельзя, верни `needs_human` с вопросом.
