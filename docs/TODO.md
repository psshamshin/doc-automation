## Идеи

| Что | Зачем |
| --- | --- |
| Проверка смысла ответа агента | Код сверяет цитаты с источником, но не проверяет, что вывод из цитаты верен. Вариант: второй проход другим агентом, который видит только цитату и вывод |
| Сузить копию документации в папке агента | Сейчас там вся рабочая копия; менять можно только страницы задания, но читать можно все |
| Сузить правило Г5 для исправлений (GUI-3916) | Исправление поведения элемента оформления (заголовок появляется и исчезает при прокрутке) правила считают заметным для пользователя. Предложение: разделить слова интерфейса на «место» (страница, заголовок, прокрутка) и «действие» (сохранение, фильтр, валидация); исправление только со словами «места» отправлять в «проверить скрины» |
| Агент ищет в документации ошибки, не связанные с задачами | Битые ссылки, опечатки, расхождения RU и EN. Список таких правок техписа из сравнения убран для чистоты эксперимента |
| Версии остальных компонентов (point-api и другие) для таблицы в release notes | Сейчас берутся из прошлого релиза с пометкой «проверить». Нужен источник |
| Переименования по значению, а не только по ключу перевода | Сейчас код заменяет название, только если текст изменился у того же ключа. Если ключ тоже переименовали, замена не находится |
| Проверка смысла строк release notes без агента | Сейчас код только показывает строки в файле проверки. Можно отмечать строки с именами компонентов и кода как требующие переписывания |
| Список языков интерфейса из кода | Задачу класса Д9 сейчас сверяет агент. Набор языков можно читать из настроек сборки |
| Критерий И4 чаще срабатывает на общих файлах переводов | Уйдет после точной привязки по истории git |
