# Как проверить результат

Код пайплайна (шаги 1-2) не использует случайность, время и сеть. Одинаковые входные папки и одинаковый
код дают одинаковые файлы байт в байт. Ниже - как в этом убедиться.

## 1. Проверка без входных папок (2 секунды)

```bash
python3 -m py_compile pipeline/*.py
python3 -m unittest discover -s tests
```

Ожидается: `Ran 49 tests ... OK`. Тест `test_rerun_is_identical` запускает пайплайн на придуманных данных
дважды и сравнивает контрольные суммы всех результатов.

Полный прогон на придуманных данных и его контрольная сумма:

```bash
python3 -m pipeline.run --config config/release-fixture.json --force
shasum -a 256 runs/fixture/report.md
```

Ожидается:

```
c20041541737967b8bf01e97c5d196dbedea766d4a705245cf69a723e94dca11  runs/fixture/report.md
```

Эти данные лежат в репозитории, поэтому сумма должна совпасть на любой машине. Тот же файл CI сохраняет
как артефакт `fixture-report`.

## 2. Проверка на реальных данных релиза 2.3.0

Нужны четыре входные папки (см. README, раздел 4). Папка `jira/` пустая.

```bash
python3 -m pipeline.run --config config/release-2.3.0.json
shasum -a 256 runs/2.3.0/report.md runs/2.3.0/05_units.json
```

Ожидается:

```
cd296449d53663a1133ba12116cdd2aadcad6f1cdd0200c291559e030102300a  runs/2.3.0/report.md
a1e911833fec0c7e766848adde3eaa7067a2b8b82af1dd10fcef74c2176475de  runs/2.3.0/05_units.json
```

Суммы верны для кода и правил из коммита, в котором этот файл менялся последний раз, и для пустой папки
`jira/`. После любой правки правил или после загрузки задач Jira суммы изменятся: тогда сверяйте таблицу
решений (ниже) и обновите суммы здесь.

Если сумма `05_units.json` не совпала, а `report.md` совпала: в `05_units.json` есть счетчики строк из
стандартного модуля `difflib`, они могут отличаться между версиями Python. Суммы получены на Python 3.15.

Проверить, что повторный запуск ничего не меняет:

```bash
shasum -a 256 runs/2.3.0/*.json runs/2.3.0/report.md > /tmp/run_a.txt
python3 -m pipeline.run --config config/release-2.3.0.json
shasum -a 256 runs/2.3.0/*.json runs/2.3.0/report.md > /tmp/run_b.txt
diff /tmp/run_a.txt /tmp/run_b.txt && echo "одинаково"
```

## 3. Таблица решений для релиза 2.3.0

Вывести текущую таблицу:

```bash
grep '^| GUI' runs/2.3.0/report.md
```

Сравнить с первым прогоном (до исправления правил; файл лежит локально, в git не попадает):

```bash
diff <(grep '^| GUI' runs/2.3.0/report_run1.md | sort) <(grep '^| GUI' runs/2.3.0/report.md | sort)
```
