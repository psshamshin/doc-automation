# Входные данные

Сложите сюда архивы (или распакованные папки) для релиза, который нужно разобрать. Содержимое в git не
попадает.

| Что положить | Обязательно |
| --- | --- |
| Код фронтенда предыдущего релиза | да |
| Код фронтенда нового релиза | да |
| Документация предыдущего релиза | да |
| Документация нового релиза от техписа (только для сравнения) | нет |
| Выгрузка задач Jira: XML, CSV, JSON или текст | нет |

Создавать папки и переименовывать ничего не нужно. Архивы `.zip` и `.tar.gz` пайплайн распакует сам в
`_unpacked/`. Что код, а что документация, определяется по содержимому; что старое, а что новое - по версиям.

Проверить, что все нашлось: `python3 -m pipeline versions`.

Несколько наборов данных сразу: положите каждый в свою папку `input/<имя>/` и указывайте имя в командах.
