# Входные данные

Каждая папка здесь - один набор данных для одного прогона. Имя папки любое (например, `2.3.0`).
Содержимое в git не попадает.

Внутри набора данных пять папок с фиксированными именами:

| Папка | Что положить | Обязательно |
| --- | --- | --- |
| `source-code-old` | Исходный код фронтенда предыдущего релиза | да |
| `source-code-new` | Исходный код фронтенда нового релиза | да |
| `docs-previous-release` | Документация предыдущего релиза | да |
| `docs-reference` | Документация нового релиза, написанная техписом. Нужна только для сравнения | нет |
| `jira-tasks` | Выгрузка задач Jira: XML, CSV, JSON или текст | нет |

Архив из GitLab можно распаковать прямо в нужную папку как есть: лишний уровень вложенности
(`source-code-new/lerna-.../apps`) пайплайн пропустит сам. Версии в именах папок не нужны: они читаются
из самих данных.

Проверить, что все лежит правильно: `python3 -m pipeline versions <имя набора>`.
