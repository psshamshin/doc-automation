# Входные данные

Сложите сюда архивы (или распакованные папки): код фронтенда предыдущего и нового релиза, документацию предыдущего
релиза; по желанию - выгрузку задач Jira (XML, CSV, JSON, текст). Содержимое в git не попадает.

Папки создавать и переименовывать не нужно. Архивы `.zip` и `.tar.gz` распаковываются сами в `_unpacked/`. Что код, а
что документация, определяется по содержимому; что старое, а что новое - по версиям. Проверка: `python3 -m pipeline versions`.

Документацию нового релиза от техписа сюда не кладите, если собираетесь запускать агента: см. `reference/README.md`.
