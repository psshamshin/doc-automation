# Результаты

Для каждого прогона создается `output/<версия релиза>/`. Содержимое в git не попадает.

| Что | Содержимое |
| --- | --- |
| `review.md` | Файл проверки: единственное, что нужно проверить человеку |
| `checks.md` | Сквозные проверки документации |
| `jira_query.txt` | Запросы для выгрузки задач из Jira |
| `result/` | Документация RU и EN с внесенными правками, `trace.md`, `screenshots.md` |
| `agent_workspace/` | Папка агента: задания, ответы, документация для чтения, источники |
| `agent/summary.md` | Журнал работы агента: что принято и внесено, что отклонено и почему, время |
| `agent/progress.md` | Ход работы со слов агента |
| `data/` | Промежуточные данные сбора (`05_units.json` - все данные по задачам) |
| `compare/compare.html` | Сравнение с документацией техписа в три колонки |
