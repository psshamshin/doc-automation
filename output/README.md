# Результаты

Для каждого набора данных из `input/<имя>/` здесь создается папка `output/<имя>/`. Содержимое в git не
попадает.

| Файл или папка | Что внутри | Кто создает |
| --- | --- | --- |
| `draft.md` | Черновик: что определилось, что сделал код, решения по задачам. Читать первым | код |
| `validation.txt` | Решения по задачам для проверки человеком | код, правит человек |
| `report.md` | Подробный отчет по каждой задаче: записи, файлы, тексты интерфейса | код |
| `jira_query.txt` | Готовый запрос для выгрузки задач из Jira | код |
| `result/` | Рабочая копия документации RU и EN с правками, `trace.md`, `screenshots.md` | код и агент |
| `agent/` | Задания агенту, его ответы, журнал и итог `summary.md` | код и агент |
| `data/` | Промежуточные данные сбора и патчи кода | код |
| `reference/`, `compare/` | Сравнение с документацией техписа | код |
