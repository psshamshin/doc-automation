# Результаты

Для каждого прогона здесь создается папка: `output/<версия релиза>/`, а если данные лежат в `input/<имя>/`,
то `output/<имя>/`. Содержимое в git не
попадает.

| Файл или папка | Что внутри | Кто создает |
| --- | --- | --- |
| `review.md` | Файл проверки: версии, что сделал код, таблица задач с отметками «принять / отклонить / агенту». Единственный файл, который нужно проверить | код, отметки ставит человек |
| `checks.md` | Сквозные проверки документации: битые ссылки, названия продуктов текстом, расхождения языков, картинки | код |
| `report.md` | Подробности по каждой задаче: записи, файлы, тексты интерфейса. Читать не обязательно | код |
| `jira_query.txt` | Готовый запрос для выгрузки задач из Jira | код |
| `result/` | Рабочая копия документации RU и EN с правками, `trace.md`, `screenshots.md` | код и агент |
| `agent_workspace/` | Отдельная папка для агента: задания, ответы, рабочая копия документации, источники задач. Агенту открывается только она | код и агент |
| `agent/summary.md` | Журнал работы агента: что принято, что отклонено и почему, время по заданиям | код |
| `agent/progress.md` | Ход работы по шагам, со слов агента | агент |
| `data/` | Промежуточные данные сбора и патчи кода | код |
| `compare/compare.html` | Страница сравнения в три колонки: было, пайплайн, техпис | код |
| `reference/`, `compare/` | Остальные файлы сравнения. Перед запуском агента эти папки нужно убрать | код |
