# Шаг 3. Анализ изменений

**Вход:** `runs/<release>/report.md`, `runs/<release>/05_units.json`, патчи `runs/<release>/code/patches/`,
`runs/<release>/03_i18n_rows.json`, исходники `lerna-@vlapps-point@<new>/` (для контекста).
**Выход:** `runs/<release>/07_analysis.json` по схеме `schemas/analysis.schema.json`.

## Что сделать

Для каждой единицы, у которой `decision.action` не `skip`:

1. Прочитать строки ченджлога, описание задачи Jira (если есть) и патчи привязанных файлов.
2. Описать **что изменилось для пользователя**: на каком экране, какой элемент, было → стало.
   Названия элементов брать из строк интерфейса (`03_i18n_rows.json` → `new`, локали `ru` и `en`),
   а не придумывать.
3. Уточнить класс по группе Д (`class`): Д1 новый раздел, Д2 новая функция, Д3 изменение поведения или
   структуры, Д4 переименование, Д5 поля и валидация, Д6 права, Д7 удаление, Д8 пользовательский фикс,
   Д9 локализация, Д10 администрирование, Д11 breaking change.
4. Для `review`: решить продукт (`point2` / `other`) и видимость, указать, по какому сигналу в коде.
   Если сигналов нет — `needs_human`, вопрос в `open_questions`.
5. Для `rn_and_check_doc`: проверить, не описывает ли базовая дока ошибочное поведение
   (`doc_mentions` в единице, поиск по `output/MD_rus/docs`).
   Для `rn_and_check_langs` (Д9): проверить в коде, какие языки интерфейса доступны пользователю, и сверить
   со списком языков в доке. Править только этот список, `in_doc: true` только если он устарел.
6. Сформулировать строку release notes (RU и EN) — коротко, языком пользователя, без компонентов
   и номеров задач. Для невидимых изменений — `null`.

Также просмотреть `unattributed_files` в `05_units.json`: если среди них есть видимые изменения
`apps/point` без записи в ченджлоге, добавить их как единицу `id: "NOCL:<путь>"` с `source: "code_only"`.

## Чего не делать

- Не читать `luna-point-2.3.0/`, `runs/*/_etalon/`, `runs/*/compare/`.
- Не менять решения `skip` без явной причины из кода; если меняешь — `override_reason`.
- Не писать текст доки на этом шаге.
