# Документация техписа для сравнения

Сюда можно положить документацию нового релиза, написанную техписом (архив или папку), чтобы команда
`compare` сравнила с ней результат. Содержимое в git не попадает.

Зачем отдельная папка. Агент не должен видеть эту документацию, иначе сравнение теряет смысл. Поэтому
на время работы агента ее в проекте быть не должно: команда `agent` откажется запускать агента, если
найдет ее здесь, во входных данных или в результатах сравнения. Порядок такой:

1. `collect` и `agent` выполняются без документации техписа.
2. После агента положите ее сюда (или в любое место и укажите `compare --reference <папка>`).
3. `python3 -m pipeline compare`.
4. Перед следующим запуском агента уберите ее и папки `output/<релиз>/reference`, `output/<релиз>/compare`.
