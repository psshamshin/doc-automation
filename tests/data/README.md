# Придуманные данные для тестов

Все файлы здесь придуманы: это не код и не документация настоящего продукта.

Папка `demo/` устроена так же, как набор данных в `input/`:

- `source-code-old`, `source-code-new` - маленькая монорепа на двух версиях интерфейса (1.0.0 и 1.2.0);
- `docs-previous-release`, `docs-reference` - мини-документация RU/EN до и после релиза;
- `jira-tasks` - пусто;
- `dataset.json`, `doc_map.json` - своя карта "код -> страница документации".

Запуск: `python3 -m pipeline collect tests/data/demo`. Результаты пишутся в `output/demo/` (в git не попадают).
